Sources and data

Every report cited in the book and every data series behind its charts, with where each came from and when it was retrieved.

Reports and documents

Status shows how far each source was read. Read: the cited pages were read in full. Summary: only a summary or a short page was read, enough for a date or title. Title only: only the title was confirmed; nothing else from it is used.

Data series

Each series is downloaded by scripts/fetch.py and cleaned by scripts/build_data.py; raw files and a fetch log with checksums are in data/raw/. To refresh everything, run those two scripts and then scripts/build_site_meta.py.

How to refresh the data

python3 -m venv .venv && .venv/bin/pip install pandas xlrd openpyxl
.venv/bin/python scripts/fetch.py all
.venv/bin/python scripts/build_data.py
.venv/bin/python scripts/derive_phase3.py
python3 scripts/build_site_meta.py
python3 scripts/check_numbers.py && python3 scripts/check_links.py

A refresh brings in a newer IMF vintage when one is published. Numbers quoted in the text are tied to the data by scripts/check_numbers.py, which reports any figure that no longer matches.
